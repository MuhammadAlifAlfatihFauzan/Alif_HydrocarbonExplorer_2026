ASEDERHANAKAN
Analogi Geometri Valensi
C — KARBON
C = Segi Empat (Persegi)
Valensi karbon = 4 — mampu membentuk 4 ikatan kovalen.
Segi empat memiliki 4 sisi datar → masing-masing sisi = 1 ikatan.
H — HIDROGEN
H = Semiellips / Setengah Elips
Valensi hidrogen = 1 — hanya mampu membentuk 1 ikatan kovalen.
Semiellips memiliki 1 sisi datar → sisi datar selalu menghadap atom C yang diikat.
Jumlah Sisi Datar ≈ Jumlah Ikatan
C → 4 sisi datar → valensi 4| H → 1 sisi datar → valensi 1
⚠ Ini adalah model visual untuk mempermudah pemahaman valensi, bukan representasi struktur elektron sebenarnya.

Validasi Model
Kondisi Batas — n=1
Alkana n=1 → CH₄ (4H) — ada ✅
2(3)+(1-2)(2)=4
Alkena n=1 → CH₂ (2H) — tidak ada ❌
2(2)+(1-2)(2)=2
Alkuna n=1 → CH₀ (0H) — tidak ada ❌
2(1)+(1-2)(2)=0
Membuktikan bahwa Total = 2a + (n−2)b menghasilkan ketiga rumus hidrokarbon
Total = 2a + (n−2)b = 2a + nb − 2b
ALKANA
a=3 · b=2
2(3) + n(2) − 2(2)
= 6 + 2n − 4
= 2n + 2 ✅
ALKENA
a=2 · b=2
2(2) + n(2) − 2(2)
= 4 + 2n − 4
= 2n ✅
ALKUNA
a=1 · b=2
2(1) + n(2) − 2(2)
= 2 + 2n − 4
= 2n − 2 ✅
Dengan b=2 tetap dan a berubah (3→2→1) — satu rumus menghasilkan ketiga rumus standar.
Mengapa Jumlah H Berkurang? (IHD)
Setiap satu ikatan rangkap mengambil 2 atom H dibanding alkana (jenuh):
Alkana (a=3): IHD=0 → jenuh, H maksimal
Alkena (a=2): IHD=1 → satu rangkap dua → 2 H lebih sedikit
Alkuna (a=1): IHD=2 → satu rangkap tiga → 4 H lebih sedikit
IHD = 3 − a
Bentuk sederhana khusus model ini.
Rumus umum kimia organik:
IHD = (2C + 2 − H) / 2
C = jumlah karbon · H = jumlah hidrogen
⚠ IHD secara umum juga menghitung struktur cincin — di luar cakupan model rantai lurus ini.
Ruang Lingkup Model
Hidrokarbon rantai lurus tak-siklik (alkana, alkena, alkuna)
Struktur siklik, bercabang, dan aromatik — di luar cakupan model ini
Pengembangan lanjutan dapat memperluas analogi geometri ke struktur siklik, bercabang, dan aromatik.
