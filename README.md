# Alif Hydrocarbon Pattern Explorer 2026

An interactive visual simulator for learning hydrocarbon homologous series (alkane, alkene, alkyne) through the A-B-A pattern generalization approach.

## How to Use

1. Download `Alif_HydrocarbonExplorer_2026_PROTECTED.html`
2. Open in any browser (Chrome, Firefox, or Edge)
3. No installation or internet connection required

## Features

- SINGLE and COMPARE ALL modes
- Interactive slider n = 1–10
- Dynamic mathematical proof panel
- Atom Geometry Principle
- Boundary condition visualization (n = 1)
